# Superseded: manual champion Draft proposal

The manual-request proposal is superseded by the [automatic live Draft contract](live-draft-contract.md) for issue #4. Read that document and its [synthetic event timelines](draft-fixtures.json) instead.

The goal is automatically refreshed champion recommendations on a second screen or overlay, not a per-match form or user-provided candidate list. The live product contract is approved with pick scores from 5.0 to 0.0. No Draft runtime, LCU integration, ranking model or overlay is implemented by these artifacts; [investigation #8](https://github.com/Eduvent/riftwise/issues/8) carries real-client feasibility, data-source and score-design work. The existing manual **item/recipe** planner is independent and unchanged.
